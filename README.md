# Conejo Valley Family Counseling — Exact Homepage Clone

An exact, high-fidelity reproduction of [Conejo Valley Family Counseling](https://www.conejovalleycounseling.com/home), built with Next.js, React, Tailwind CSS, and TypeScript.

## 🚀 Tech Stack

- **Framework**: Next.js 16 (App Router with Turbopack)
- **UI Library**: React 19
- **Styling**: Tailwind CSS v4 with custom design tokens
- **Typography**:
  - `PrintedMoments` (authentic custom script font)
  - `Cormorant Garamond` (Google Fonts serif)
  - `Mulish` (Google Fonts sans-serif)
- **Language**: TypeScript
- **Deployment**: Vercel ready (`vercel.json`)

## 📦 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Miteshreddy/Grow_My_Therapy.git
cd Grow_My_Therapy
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
npm start
```

## 🌐 Deploy to Vercel

This repository includes first-class support for Vercel deployment:

1. Push to your GitHub repository.
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import the `Grow_My_Therapy` repository.
4. Vercel will automatically detect Next.js and deploy with zero manual configuration.
